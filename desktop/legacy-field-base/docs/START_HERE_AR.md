# ابدأ من هنا — مختبر أساس V7.0.0

1. انسخ مجلد `web` إلى خادم النظام المركزي.
2. شغّل `python server.py` للاختبار المحلي.
3. استخدم `field` كمشروع Android الميداني المرتبط بنفس الـCentral API.
4. لا تضع أي Token أو مفتاح API داخل JavaScript أو المستودع.
5. قبل النشر غيّر كلمة مرور المدير الافتراضية وأكمل إعداد HTTPS وOTP وقاعدة البيانات المركزية.
6. استخدم ملف `assets/واجهة_مختبر_أساس_المعتمدة.png` كمرجع بصري للواجهة الجديدة.

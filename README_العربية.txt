نظام مختبر أساس LIMS — V7.2.0 Final

واجهة عربية RTL متجاوبة لإدارة المشاريع وأوامر العمل والعينات والاختبارات والتقارير والبرنامج الميداني.

التشغيل على Windows:
1. قبل أول تشغيل فقط، عيّن متغير البيئة المحلي LIMS_BOOTSTRAP_PASSWORD إلى كلمة مرور قوية من 12 حرفاً أو أكثر.
2. شغّل الملف تشغيل_نظام_أساس.bat أو نفّذ python server.py.
3. افتح المتصفح على http://127.0.0.1:8080.
4. استخدم حساب admin الذي أُنشئ بكلمة المرور المحلية، ثم أنشئ الحسابات والأدوار الأخرى من النظام.

يشمل الإصدار:
- Dashboard للأولويات والعوائق وطابور المزامنة.
- إدارة المشاريع في Table وBoard/Kanban وRoadmap.
- ربط المشروع بأوامر العمل والعينات والاختبارات والنتائج والتقارير والزيارات الميدانية.
- مراجعة واعتماد وسجل تدقيق وصلاحيات.
- ترقية آمنة وغير هدّامة لقاعدة البيانات القائمة.

الأمان:
- لا تحفظ كلمة مرور أو API key أو سر في Git.
- لا تضف lims.db أو ملفات البيئة إلى المستودع.
- يجب تغيير كلمات المرور دورياً وفق سياسة المختبر.

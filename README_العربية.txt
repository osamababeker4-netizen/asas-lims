نظام مختبر أساس - الإصدار الأول للبرنامج الميداني

المرجع:
تم اعتماد تفاصيل البرنامج الميداني من الفيديو المرسل، مع هوية مختبر أساس.

التشغيل على Windows:
1) افتح هذا المجلد.
2) شغّل الملف: تشغيل_نظام_أساس.bat
   أو من CMD داخل المجلد: python server.py
3) افتح المتصفح على:
   http://127.0.0.1:8080
4) بيانات الدخول الافتراضية:
   المستخدم: admin
   كلمة المرور: 1234

مهم:
- إذا كان لديك lims.db قديم، احتفظ بنسخة احتياطية قبل استبدال الملفات.
- لا تحذف lims.db؛ السيرفر يضيف جدول البرنامج الميداني تلقائيًا عند التشغيل.
- النسخة الحالية تضيف شاشة البرنامج الميداني، البحث برقم الرخصة، بيانات المقاول/المشروع/القطاع/الطبقة، الاختبارات، GPS، الصور والمعاينة، الملاحظات، والحفظ وسجل الزيارات.
- إدارة المستخدمين والصلاحيات التفصيلية ستُستكمل في المرحلة التالية.


الإصدار V2: تمت إضافة إدارة المستخدمين والصلاحيات بالأدوار: مدير نظام، مدير، فني مختبر، مفتش ميداني. الصلاحيات مطبقة من الخادم وليس الواجهة فقط.

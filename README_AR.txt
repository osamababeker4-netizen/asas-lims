مختبر أساس LIMS — الإصدار V7.2.0 Final

هذه نسخة عربية RTL لإدارة المختبر والمشاريع، مع المحافظة على البرنامج الميداني المحلي وواجهة API المركزية القابلة للربط.

أبرز القدرات:
- لوحة قيادة تشغيلية للأولويات والعوائق والمراجعات وطابور المزامنة.
- إدارة المشاريع بطرق عرض جدول وKanban وخارطة طريق.
- ربط المشروع بأوامر العمل والعينات والاختبارات والنتائج والتقارير والزيارات الميدانية.
- مستخدمون وأدوار وصلاحيات وسجل تدقيق.
- دورة مراجعة واعتماد للمشاريع والزيارات والتقارير.
- ترحيل قاعدة SQLite غير هدّام لقواعد البيانات القائمة.
- طابور مزامنة محلي يحافظ على نهج Local-First قبل الربط مع Central API.
- تصميم متجاوب لسطح المكتب والجوال.

التشغيل المحلي:
1. عيّن متغير البيئة LIMS_BOOTSTRAP_PASSWORD محلياً إلى كلمة مرور قوية من 12 حرفاً أو أكثر قبل أول تشغيل.
2. شغّل: python server.py
3. افتح: http://127.0.0.1:8080
4. بعد أول دخول، أنشئ المستخدمين والأدوار اللازمة من شاشة المستخدمين والصلاحيات.

لا تضع كلمات مرور أو API keys أو ملفات قاعدة بيانات أو إعدادات بيئية في Git.
لا تستخدم ملف ZIP كمصدر للتطوير؛ ملفات المصدر الفعلية هي HTML وCSS وJavaScript وPython وSQL في جذر المشروع.

ملاحظة اعتماد:
يلزم للاعتماد الرسمي ISO/IEC 17025 أو SAAC تنفيذ IQ/OQ/PQ، التحقق من طرق الاختبار والحسابات، إجراءات التشغيل، النسخ الاحتياطي والاستعادة، اختبار الأمن، ربط الأجهزة، والتحقق من Central API في بيئة معتمدة.

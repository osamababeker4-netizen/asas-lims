مختبر أساس LIMS — V5 Production Field Edition

تمت ترقية المشروع من V4 إلى V5 كنسخة موسعة قابلة للبناء على Android، مع بنية Local-First جاهزة للربط المركزي.

أهم ما تمت إضافته:
1) إدارة المستخدمين والأدوار والصلاحيات.
2) كلمات مرور مجزأة مع Salt بدل التخزين النصي.
3) OTP لكل دخول مع مدة صلاحية 5 دقائق وتخزين الرمز كتجزئة.
4) Audit Trail للعمليات الحساسة.
5) إدارة العملاء والمشاريع والاستشاري والمقاول.
6) عروض الأسعار والعقود وطلبات العملاء وأوامر العمل والفواتير والشكاوى.
7) إدارة العينات مع QR وGPS ومواقع التخزين.
8) دليل اختبارات موسع للتربة والخرسانة والأسفلت واختبارات إضافية.
9) حسابات D2216 وD4318 وD1883 وD1557/D698 الأساسية، مع حفظ البيانات الخام.
10) إدارة الأجهزة والمعايرة والصيانة وحركة الأجهزة.
11) NCR وتقارير عدم المطابقة.
12) التقارير مع دورة مراجعة واعتماد نهائي وصلاحية Reviewer/Admin.
13) PDF ومشاركة التقرير.
14) إعدادات الاختبارات وحدود القبول.
15) طابور مزامنة Local Queue وربط Central API.
16) Backup SQL قابل للنقل.
17) Central API reference في مجلد central-api.

بيانات الدخول لأول تشغيل:
admin / 1234
يجب تغيير كلمة المرور وربط SMS Gateway قبل التشغيل الفعلي.

مهم للاعتماد:
البرنامج أصبح أساساً تقنياً قوياً، لكن الاعتماد الرسمي ISO/IEC 17025 أو SAAC لا يعتمد على الكود وحده. يلزم تنفيذ IQ/OQ/PQ، التحقق من طرق الاختبار والحسابات، صلاحيات المستخدمين، إدارة الوثائق والسجلات، اختبار النسخ الاحتياطي والاستعادة، اختبار الاختراق، ربط SMS الحقيقي، ربط الأجهزة، واختبار API المركزي قبل إصدار شهادة الاعتماد.

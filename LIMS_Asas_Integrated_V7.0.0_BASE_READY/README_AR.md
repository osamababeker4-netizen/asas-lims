# مختبر أساس LIMS — النسخة المتكاملة V7.0.0

هذه الحزمة هي **نقطة الأساس الموحدة** للتطوير والتشغيل، وتجمع نسخة الويب المركزية مع مشروع Android الميداني ووحدة بلدي ورخص الحفريات وتكامل واتساب/تلغرام.

## مكونات الحزمة
- `web/` — واجهة LIMS العربية RTL + Central API (Python/SQLite) + PWA.
- `field/` — مشروع Android الميداني V5.1.0 مع بنية Local-First ووحدة بلدي ورخص الحفريات.
- `assets/واجهة_مختبر_أساس_المعتمدة.png` — مرجع الواجهة المعتمد للتطوير البصري.
- `docs/` — تعليمات التشغيل والدمج.

## تشغيل الويب محليًا
يتطلب Python 3.9+:

```bash
cd web
python server.py
```
ثم افتح `http://localhost:8080`.

## بناء Android
من مجلد `field`:

```bash
./gradlew assembleDebug
```
وللإصدار:

```bash
./gradlew assembleRelease
```

## مهم قبل التشغيل الفعلي
هذه الحزمة **نسخة أساس متكاملة للتطوير والتجهيز وليست شهادة اعتماد رسمية**. يجب قبل الإنتاج تغيير بيانات الدخول الافتراضية، تفعيل HTTPS، ربط OTP/SMS الحقيقي، إدارة الأسرار بمتغيرات بيئة، استخدام قاعدة بيانات مُدارة عند التوسع، اختبار النسخ الاحتياطي والاستعادة، اختبار الأمن والصلاحيات، والتحقق من طرق الاختبار والحسابات والتقارير وفق نظام الجودة المعتمد.
